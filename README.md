# Красим окна

Сайт реставрации деревянных окон, покраски ПВХ и алюминия и сервиса окон для Москвы и Московской области: [krasimokna.ru](https://krasimokna.ru).

## Разработка

Нужны Node.js и npm.

```sh
npm i
npm run dev
```

Приложение откроется на [http://localhost:8080](http://localhost:8080).
